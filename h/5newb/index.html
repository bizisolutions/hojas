1

Las 3 a 5 preguntas que hoy no pueden responder

⏱ Media hora · lo puede escribir una sola persona

No una lista de indicadores: las decisiones que hoy se toman a ciegas.
Sí sirve: «¿cuánto deja realmente cada sede, después de nómina?»
No sirve: «un tablero de ventas» — eso es un mueble, no una pregunta.

Con tres basta. De acá sale el alcance, y por lo tanto el precio: un tablero que no responde una pregunta concreta no se abre dos veces.

2

El acuerdo de confidencialidad

⏱ Un día, casi siempre · acá no hay nada que escribir

El nuestro o el de ustedes, como prefieran — nos da igual cuál, y si tienen modelo propio se firma ese sin discutirlo. Nadie manda datos de verdad sin esto, y con datos de mentira la propuesta también sale de mentira.

3

Los archivos, de dónde salen y quién los maneja

⏱ Una hora de quien maneja el sistema

Un mes de datos basta — no hace falta el histórico completo todavía. Y lo importante no es el archivo: es saber de qué sistema salió y a quién preguntarle. Eso es lo que separa una carga automática todas las noches de alguien pegando un Excel cada lunes: cambia el precio y cambia lo que se puede prometer.

Con describir uno o dos ya se puede trabajar. Hay espacio para cinco; llena los que necesites y deja el resto en blanco — los vacíos no se mandan.

Archivo 1

Tal como aparece cuando lo exportas, con todo y el final: ventas_enero.csv. Si el nombre cambia cada mes, escríbelo como sea: ventas_<mes>.xlsx.

Son las letras que van después del último punto del nombre. Si no las ves, elige «Otro, o no sé»: con el nombre lo resolvemos nosotros.

En tus palabras. Ayuda decir tres cosas: qué es cada fila (¿una venta? ¿una factura? ¿un día?), qué periodo cubre (¿un mes? ¿todo el año?) y cada cuánto se genera (diario, semanal, cuando alguien se acuerda).
Ej.: «una fila por cada venta; trae fecha, sede, producto, cantidad y valor; sale del POS todas las noches».

El nombre del programa donde le das «Exportar»: el punto de venta, el contable, el de nómina, el de reservas. Siigo, World Office, Alegra, Zeus, Square, Cloudbeds… Si el archivo lo escribe alguien a mano en Excel, eso también es una fuente: dilo así («lo llena Marcela cada lunes»).

Una API es una puerta por la que dos programas se pasan la información solos, sin que nadie exporte ni copie nada. Con API, el tablero se actualiza cada noche sin que ustedes hagan nada; sin ella, alguien tiene que exportar el archivo cada cierto tiempo. No saber está perfectamente bien: es una pregunta para el proveedor del programa, y la podemos hacer nosotros.

Y una cosa más: quién decide

Quien aprueba el alcance y el presupuesto. Puede ser una de las personas de arriba; lo que no puede pasar es que no sea nadie. Es la razón más común por la que un proyecto de datos se detiene: aparece una duda y no hay a quién preguntarle.
